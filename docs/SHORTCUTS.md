# Keyboard shortcuts

LinAmp follows the classic Winamp 2.x shortcut set. Keys work whenever a LinAmp
window has focus and no text field is active, in both the classic skin and the
modern view. The global media keys (below) work even when LinAmp is unfocused.

## Playback

| Key | Action |
| --- | --- |
| X | Play |
| C | Pause (press Space or X to resume) |
| V | Stop |
| Shift+V | Stop with a fade-out |
| Ctrl+V | Toggle "stop after current track" |
| B | Next track |
| Z | Previous track |
| Space | Play / pause |
| Ctrl+Z | Jump to the start of the playlist |
| Ctrl+R | Reverse the playlist order |
| R | Toggle Repeat |
| S | Toggle Shuffle |

## Volume and seeking

| Key | Action |
| --- | --- |
| Up / Down | Volume up / down (moves the selection in the playlist window) |
| Left / Right | Seek back / forward 5 seconds |

## Numeric keypad

Off by default, enable "Numeric keypad" under Preferences > Optional Features.
When on, the keypad mirrors Winamp's transport controls (note: these also fire
for the top number row).

| Key | Action |
| --- | --- |
| 0 | Open file(s) |
| 5 | Play |
| 4 / 6 | Previous / next track |
| 8 / 2 | Volume up / down |
| 9 / 7 | Seek forward / back 5 seconds |
| 3 / 1 | Skip forward / back 10 tracks |

## Files and tags

| Key | Action |
| --- | --- |
| L | Open file(s) |
| Shift+L | Open folder |
| Ctrl+L | Open location (stream a URL) |
| J | Jump to file |
| Ctrl+J | Jump to time |
| Alt+I | Bookmark the current track |
| Alt+3 | Edit the current file's tags (opens the mass editor when more than one playlist row is selected) |

## Windows

| Key | Action |
| --- | --- |
| Alt+G | Show / hide the Equalizer |
| Alt+E | Show / hide the Playlist |
| Alt+L | Show / hide the Media Library |
| Ctrl+D | Toggle double size (1x / 2x) |
| Ctrl+P | Open Preferences |
| Ctrl+T | Toggle elapsed / remaining time |
| Ctrl+A | Toggle always on top (selects all when the playlist has focus) |

## Playlist window

| Key | Action |
| --- | --- |
| Up / Down | Move the selection (Ctrl adds rows, Shift extends the range) |
| Home / End | Select the first / last track |
| Enter | Play the selected track |
| Ctrl+A | Select all (toggles always on top from the other windows) |
| Insert | Add file(s) |
| Delete | Remove the selected tracks |

## Global media keys

The keyboard media / transport keys control LinAmp even when it is unfocused,
minimized, or hidden to the system tray (Windows media hotkeys; MPRIS on Linux).

| Key | Action |
| --- | --- |
| Media Play / Pause | Play / pause |
| Media Stop | Stop |
| Media Previous | Previous track |
| Media Next | Next track |

## Tag editor window

Active while the tag editor ("File Info") window has focus.

| Key | Action |
| --- | --- |
| Alt+B | Basic Info tab |
| Alt+I | ID3 tab (MP3 / MP2 / MP1) |
| Alt+A | Tags tab (FLAC / Ogg / M4A) |
| Alt+1 / Alt+2 | Toggle the ID3v1 / ID3v2 tag (ID3 tab) |
| Alt+U | Update (save tags) |
| Alt+C / Escape | Cancel (close without saving) |
| Alt+T / Alt+F | Copy to / from ID3v1 (MP3, ID3 tab) |

## Mouse

| Gesture | Action |
| --- | --- |
| Mouse wheel over the main window | Adjust volume |
| Double-click an EQ band, the preamp or the balance slider | Reset it to centre |
| Right-click the Stop button | Stop options (stop, stop after current, stop with fade) |
| Right-click elsewhere on the main window | Options menu |
